Aquest és el post per defecte. L'estic modificant per provar la **Sintaxi Avançada (Estesa)** de Markdown, seguint la [guia oficial](https://www.markdownguide.org/extended-syntax/).

### 1. Taules (Tables)

Aquí hi ha una taula per organitzar dades:

| Sintaxi | Descripció | Dificultat |
| :--- | :--- | :---: |
| Capçalera | Títol | Fàcil |
| Paràgraf | Text | Fàcil |
| Ratllat | ~~Text~~ | Mitja |


### 2. Blocs de Codi (Fenced Code Blocks)

Molt útil per a tutorials tècnics. Podem especificar el llenguatge, per exemple `javascript`:

```javascript
function helloWorld() {
  console.log("Hello, world!");
}
helloWorld();
```

### 3. Llistes de Tasques (Task Lists)
Això és perfecte per seguir el progrés del projecte:

[x] Instal·lar Jekyll

[x] Crear el repositori a GitHub Pages

[x] Modificar la pàgina "About"

[x] Modificar aquest post (ho estic fent!)

[ ] Crear la pàgina "Serveis"

### 4. Text Ratllat (Strikethrough)
Podem ratllar text que ja no és vàlid, com ~~aquesta paraula~~.
